# Politique de sécurité

## Signaler une vulnérabilité

Merci de **ne pas** publier de faille de sécurité dans une issue publique.

Merci d'ouvrir une issue privée de sécurité GitHub (Security Advisory) avec :

- description du problème ;
- impact potentiel ;
- étapes de reproduction ;
- proposition de correction (si disponible).

## Bonnes pratiques pour les contributions

- Ne commitez pas de secrets (mots de passe, clés API, tokens).
- Vérifiez les variables d'environnement avant publication.
- Testez les changements de sécurité (auth, paiement, validation serveur) avant fusion.
